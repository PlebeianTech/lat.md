# Prototype-Named Directory

`constructor` is a key every plain object inherits from `Object.prototype`, so
a directory of this name must not be mistaken for a Diátaxis mode directory.

## A heading

The first paragraph under a heading is the permitted summary.

This second paragraph is narrative prose and must be flagged, which can only
happen if the declared reference mode survives the directory lookup.
